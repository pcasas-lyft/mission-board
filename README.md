# todo-tracker

A lightweight task tracker built for working with Claude Code agents. Tasks live in a local JSON file, a Python server serves a web UI and REST API, and Claude Code hooks keep everything in sync automatically.

**What it does:**
- Web UI at `localhost:3456` to manage tasks (drag to reorder, inline editing, subtasks)
- Agents read `WORKSTATUS.md` at session start to see what's in flight
- When an agent finishes, it updates the task status and you get a Mac notification with the task name
- Branch naming convention auto-claims tasks when you create a worktree

## Prerequisites

- **macOS** (launchd for persistent server; Linux/Windows work but need manual server start)
- **Python 3** (`python3 --version`)
- **Claude Code** CLI
- **terminal-notifier** (optional, for clickable Mac notifications):
  ```bash
  brew install terminal-notifier
  ```
- **fswatch** (optional, for Cursor live-reload of WORKSTATUS.md):
  ```bash
  brew install fswatch
  ```

## Install

```bash
# 1. Clone wherever you keep projects
cd ~/src   # or wherever
git clone https://github.com/YOUR_USERNAME/todo-tracker.git
cd todo-tracker

# 2. Run setup
bash setup.sh
```

That's it. Setup will:
- Start the server via launchd (auto-restarts on crash, starts on login)
- Install the `/status` slash command in Claude Code
- Merge the Claude Code hooks into `~/.claude/settings.json`
- Create a `CLAUDE.md` in the parent directory (your workspace root) so agents know how to use the tracker

**3. Restart Claude Code** (or run `/hooks` in a session) to activate the hooks.

## Usage

### Web UI
Open **http://localhost:3456**. Tasks are organized by status. Click any task to edit it inline.

### With Claude Code agents
Agents automatically:
- Read `WORKSTATUS.md` at the start of every session
- Claim tasks when you create a worktree matching `feat/<task-id>-*` or `fix/<task-id>-*`
- Update task status when they finish
- Fire a Mac notification when the session ends

### `/status` command
In any Claude Code session, type `/status` to get a live briefing:
> "Right now: feat/t4-tcs-mcp is working on Add TCS MCP integration. Up next: ..."

### Creating tasks via CLI
```bash
curl -s -X POST http://localhost:3456/tasks/new \
  -H "Content-Type: application/json" \
  -d '{"title": "My new task", "status": "todo"}'
```

### Branch naming convention
Name branches after the task ID so the system auto-correlates:
```
feat/t4-tcs-mcp          → claims task with id "t4"
fix/1746001234-auth-bug  → claims task with id "1746001234"
```
Task IDs are shown in the tracker UI and in `WORKSTATUS.md`.

## Updating

When there are new changes:

```bash
cd ~/src/todo-tracker
./update.sh
```

This pulls the latest code and re-applies configuration. Your `tasks.json` is never touched.

## How it works

```
~/src/
├── CLAUDE.md           ← agent instructions (generated by setup.sh)
├── WORKSTATUS.md       ← auto-generated snapshot (gitignored)
└── todo-tracker/
    ├── server.py       ← ThreadedHTTPServer, SSE for live sync
    ├── index.html      ← single-file web UI
    ├── tasks.json      ← source of truth (gitignored, stays on your machine)
    ├── gen-status.py   ← regenerates WORKSTATUS.md
    ├── archive-tasks.py← moves done tasks >3 days old to tasks-archive.json
    ├── on-stop.sh      ← Stop hook: archives + regenerates + notifies
    ├── auto-claim-task.py    ← WorktreeCreate hook
    ├── auto-unclaim-task.py  ← WorktreeRemove hook
    ├── watch-status.sh ← fswatch watcher (optional, for Cursor)
    ├── setup.sh        ← install / reinstall
    ├── update.sh       ← git pull + reapply config
    └── templates/      ← path-substituted configs (skill, plist, CLAUDE.md)
```

### Claude Code hooks (auto-installed)

| Hook | What it does |
|------|-------------|
| `SessionStart` | Reminds agents to check WORKSTATUS.md and claim a task |
| `WorktreeCreate` | Reads branch name, PATCHes matching task to `in-progress` + sets `claimedBy` |
| `WorktreeRemove` | Clears `claimedBy` on the task so it shows as available again |
| `Stop` | Archives old done tasks, regenerates WORKSTATUS.md, sends Mac notification |

### API reference

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/tasks` | GET | Fetch all tasks |
| `/tasks/new` | POST | Append a new task |
| `/tasks/<id>` | PATCH | Update a single task ← agents use this |
| `/events` | GET | SSE stream for live UI updates |

## Troubleshooting

**Server not running:**
```bash
# Check if it's running
curl -s http://localhost:3456/tasks | head -c 50

# Start manually
python3 ~/src/todo-tracker/server.py

# Or reload the launchd agent
launchctl unload ~/Library/LaunchAgents/com.$(whoami).todo-tracker.plist
launchctl load   ~/Library/LaunchAgents/com.$(whoami).todo-tracker.plist
```

**Hooks not firing:**
- Restart Claude Code after running `setup.sh`
- Or run `/hooks` in a Claude Code session to reload config

**Notifications not showing (VS Code + Claude Code extension):**
Make sure `terminal-notifier` is installed and on PATH:
```bash
brew install terminal-notifier
which terminal-notifier  # should print a path
```

**Moved the repo to a different directory:**
```bash
bash setup.sh             # re-applies config with new paths
bash setup.sh --force-claude  # also regenerates CLAUDE.md
```
